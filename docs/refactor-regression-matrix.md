# 重构回归矩阵

## 必测视口

| 设备 | 视口 |
| --- | --- |
| 手机 | 390×844 |
| 平板竖屏 | 768×900 |
| 平板横屏 | 1024×768 |
| 桌面小窗 | 1280×800 |
| 桌面 | 1440×900 |
| 大屏 | 1920×1080 |

## 功能矩阵

| 区域 | 必测 |
| --- | --- |
| 首页 | 分页、搜索、标签筛选、无封面、最后一页、亮 / 暗、常规 / 简洁 |
| 归档 | 关键词、标签、组合筛选、空结果、URL 恢复 |
| 普通文章 | 三种封面模式、目录、纸张分页、公式、代码、图片灯箱、加密 |
| 固定链接文章 | 内容、封面模式、加密、元数据与普通文章一致；旧 URL 仍可达 |
| 友链 | 单 / 双按钮、搜索、标签、复制、长标题 |
| 番剧 | 三数据模式、两种布局、筛选、排序 |
| 相册 | 索引、详情、懒加载、滚动加载、瀑布流跨列、灯箱、返回 |
| 设置 | 开关即时生效、恢复默认、刷新与切页一致 |
| Swup | 连续 20 次跳转、双击、两链接竞态、前进 / 后退、同 URL、锚点 |

## 故障注入

- `code.iconify.design` 与 `api.iconify.design` 被阻断。
- 相册图延迟 10 秒、404、连接悬挂。
- 字体请求失败。
- Pagefind 索引缺失。
- GitHub API 构建期不可访问。
- 断点图片只保留一组。

预期：页面不永久空白；标题和链接可用；图片区域不塌陷；错误只告警一次。

## 自动检查

```bash
pnpm test
pnpm check
pnpm build
```

`pnpm test` 至少执行写作契约、配置注册表、媒体清单与静态输出检查。浏览器视觉回归在可用浏览器环境中补充执行。
