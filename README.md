# FGmagi Blog

个人博客，收录技术笔记、生活随笔与常用工具索引。
magi.pages.dev/

## 技术栈

- Astro 5 + Svelte 5 + Tailwind CSS
- TypeScript
- pnpm

## 本地运行

```bash
pnpm install
pnpm dev
```

构建与预览：

```bash
pnpm build
pnpm preview
```

## 部署

托管于 Cloudflare Pages，推送 `main` 分支后自动构建部署。

## 目录说明

- `public/assets`：网页媒体资源
- `public/data`：数据与文章（友链、追番、关于、我的等）
- `image`：PicGo 图床目录
